JOJO — сайт барбершопа (статический, без сборки)

ЧТО ЗАЛИВАТЬ НА ХОСТИНГ
  index.html
  robots.txt
  img/            (все фото)
Папку .claude и этот README загружать не нужно.
Подойдёт любой хостинг статики: Timeweb, Beget, REG.RU, Netlify, GitHub Pages, Vercel.
Файлы кладутся в корень сайта (public_html / www).

КАК РЕДАКТИРОВАТЬ
Все данные лежат в начале блока <script> внизу index.html:
  SITE      — телефон, адрес, часы работы, ссылки на запись, Telegram, карты, реквизиты
  PROMOS    — акции (картинка, текст, срок)
  SERVICES  — услуги: категория (c), название (n), цена (price), фото (img), описание (d)
              price: число в рублях, текст (например "−30%") или null = «уточняйте при записи»
  GALLERY   — фото в разделе «Работы и интерьер»
  REVIEWS   — отзывы
Новую категорию услуг создавать не нужно — она появится сама по полю c.
Новые фото кладите в папку img/ (JPG, до ~1200 px по длинной стороне).
Сайт использует сжатые копии .webp (img/*.webp) и превью (img/t/*.webp).
Новое фото можно указать как .jpg — оно будет работать и без превью.
Чтобы сжать его так же, конвертируйте в WebP (например, на squoosh.app):
полную версию — в img/, копию шириной 560 px — в img/t/, с тем же именем.

АНИМАЦИИ
Сцена «От хаоса — к стилю» (id="scene") — рисунок SVG, проигрывается сама,
пока блок виден на экране (страница при этом не останавливается).
Иконки у шагов — анимации LottieFiles (папка lottie/, плеер js/lottie_light.min.js),
перекрашены в цвета сайта. Лицензия Lottie Simple License — можно бесплатно,
в том числе в коммерческих целях.
Пользователям с включённым «Уменьшить движение» показывается без анимации.
hero-m.jpg / hero-m.webp — фото для мобильного экрана без неоновой надписи.
hero-d.webp — улучшенное (увеличенное, с повышенной резкостью) фото первого экрана для больших мониторов.
ПОСЛЕ ПОДКЛЮЧЕНИЯ ДОМЕНА
В <head> замените относительный путь в og:image на полный адрес,
например https://ваш-домен.ru/img/og.jpg — тогда превью ссылки
в Telegram/WhatsApp будет с картинкой.
